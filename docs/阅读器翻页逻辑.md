# 小说阅读器翻页逻辑

翻页模式下的取章与显示规则。两个开关组合出四种情况：单页 / 双页、开预加载 / 关预加载。

## 通用前提

- 一次阅读里请求过的章一直留在内存，回头再看不会重新请求，退出阅读器才释放。
- 页码、进度、阅读位置一律按**屏首那一栏所属的章**算。双页时最后一屏的进度到不了 100%，这是正常的。
- 双页时一屏摆两栏，栏与栏首尾相接，与章节边界无关：上一章剩一栏就摆左边，右边直接接下一章的开头。
- 加载动画只出现在紧挨着正文的那一栏上：往后翻是空出来的第一栏，往前翻是最靠右的那一栏；同一屏里更远的空栏留白。
- 全书首章之前、末章之后没有内容可等，空出来的地方留白，不转圈也不请求。
- 屏上那两栏一旦摆定就不再变：章节取进来、旧章从内存里放掉，都不会让当前屏重新配对、画面跳一下。

## 单页 + 不预加载

1. 进入阅读器，出现加载动画，取当前章。
2. 取完显示。
3. 翻到上一章 / 下一章时立刻出现加载动画，取那一章。
4. 取完显示，之后每次跨章重复这个过程。

读到章尾之前不会去取任何别的章。

## 单页 + 预加载

1. 进入阅读器，出现加载动画，取当前章。
2. 取完显示，同时在后台备好前后各一章：取正文，并提前排好版。
3. 翻到上一章 / 下一章时：
   - 已经排完版的，立刻显示，不闪加载动画；
   - 还没排完的，先出现加载动画，排完就显示。
4. 落到新的一章后继续往外备一章。

## 双页 + 不预加载

按乐观的方式翻：先当每一章都能跨屏摆下，真摆完发现不够再去取。

1. 进入阅读器，出现加载动画，取当前章。
2. 取完显示在左栏。
3. 看右栏有没有内容：
   - 有就直接显示；
   - 没有则右栏出现加载动画，去取下一章，取完摆进右栏。
4. 往后翻一屏后：
   - 两栏都空：左栏出现加载动画，取下一章；
   - 只有右栏空：右栏出现加载动画，取下一章。
5. 取回来的章只占一栏时，右栏还是空的，就换成右栏继续转圈，接着取再下一章，直到这一屏摆满或全书到头。
6. 往前翻是镜像的：整屏空白时在最靠右那一栏转圈，取回来的章落在它的末栏上。

## 双页 + 预加载

显示规则与「双页 + 不预加载」完全一致，区别只是提前把要用的章取好并排好版，所以那些加载动画通常不会出现。

- 备的是**屏首那一章的上一章**和**屏尾那一章的下一章**。屏上跨了两章时，备的是屏尾那一章往后的那一章，不是当前章的下一章。
- 因此翻过一屏后，落在左栏的那一章一定已经备好，左栏不会出现加载动画；例外只有一个：那一章还没排完版。
- 右栏仍然可能出现加载动画——按乐观翻页，右栏比预备的还远一章时才会发生。

## 滚动模式

滚动模式不分栏也不接章：读到底再往下翻、读到顶再往上翻，才切到相邻章，切的时候整屏出现加载动画。
